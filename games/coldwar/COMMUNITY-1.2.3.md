# 1.2.3 汉化更新与验证

v1.2.3 已撤回。真正从 Steam 在线启动时，原游戏的程序完整性检查会将已购买 DLC 保持为禁用。请使用 v1.2.4 或更新版迁移并恢复官方程序。本页保留撤回版的历史记录。[v1.2.4 迁移说明](COMMUNITY-1.2.4.md)

## 在设置中切换语言

本地校订在游戏已加载的翻译模组中生效时，设置页的语言选择显示“简体中文”。在主菜单选择“Русский”并关闭设置，会立即切换到游戏自带的俄文。再选“简体中文”即可切回。安装器沿用已有模组的优先顺序。

在游戏 1.2.5.8 中，原本提示“关闭设置后生效”的一次性窗口藏在设置页面后面，鼠标会被不可见的确认按钮挡住。现在说明会跟随所选语言显示在当前行，关闭设置即可应用。

太阳系仪的快捷键提示读取当前输入绑定。例如默认 O 键显示“按 O”，在隔离测试副本把同一动作绑定到 P 键后显示“按 P”。手柄提示的按下、长按和不同设备键名另有格式测试。实机改键测试使用了游戏的输入动作资源，游戏的操作设置页未提供这一项的改键按钮。

游戏自己显示的两类 Steam 启动错误也有中文提示。初始化失败时显示中文建议和 Steam 返回的完整原始诊断，同步失败时显示相应原因。按钮继续使用游戏原来的日志及确认操作。

## 67 项文本修订

三个游戏版本均逐项对照了同一批译文。两处成就条件改为“年满80岁”，达到 80 岁当天即可满足。三处财政条目分别为 2000 万、2000 万和 5000 万卢布。住房说明恢复首行后的换行，两条外交路线补回此前整段漏掉的正文及引语。事件和采访中也修复了错指主角的代词、译文自行添加的贬称、遗漏的金额和空段落标记。1987 年“黑色星期一”的说明列出复苏速度依次降至原先的 50%、33%、25% 的三个档次，并交代成因。另核对两份核裁军条约的每月影响和政治人物头像的上传提示。长句中的单字勘误按原文偏移保存，保留其余译文。[53 条语句校订](review-1.2.3.zh-CN.json) · [14 条单字勘误](proofread-1.2.3.json)

程序在三代正版游戏数据上检查了 XML 节点、顺序、属性、运行时参数、手柄占位符和字体覆盖。与 v1.2.2 的逐键对比仅发现表中的 67 项文字变化。XML 还附带一条游戏界面识别本译包用的注释。

## 安装、还原和复核

三代游戏分别从已发布的 v1.2.2 安装结果离线升级，重复安装并检查文件时间戳，再还原并重新安装。另走了从 1.2.5.6 到 1.2.5.7、再到 1.2.5.8 的连续升级。测试在临时用户目录中运行，核对中文 XML、程序集、字体、适用版本的设置场景、基包的原有状态和第三方模组选项。

对三个构建的正版程序集分别比较了 29,360、32,216 和 32,691 个原有方法。调整了其中的 6、6 和 9 个，涉及语言模组应用、设置、显示中的消息和最新版的太阳系仪键名。输出保持原程序集依赖列表。安装器校验输入和生成结果的完整 SHA-256，每个构建单独保留可还原的原件。

实机复测采用 Windows 版游戏 1.2.5.8。俄语界面选择简体中文、中文界面选择俄语，均在一次关闭设置后成功切换。太阳系仪的 O 与 P 两个绑定分别进入游戏观察。离线启动时按原顺序确认两条提示，再返回主菜单。两个历史版本完成了文件、正文、升级和还原验证。[游戏内语言、按键与提示截图](../../docs/runtime-labels.webp)

单独停用本地译包后，设置重新显示“English”，游戏提示也恢复英语。另将一个带独有测试文本的翻译模组放在本地校订之后，并实机确认后载模组生效。首条 Steam 诊断及其“Open log file”“OK”按钮使用原文，后续两条消息和设置页也沿用实际胜出的翻译。

可在 Windows 上从仓库根目录运行源码测试。全量字体与文本审计还需要自己拥有的游戏和工坊基包。

```powershell
py -3.12 tools/check_release.py
py -3.12 -m unittest discover -s games/coldwar -p "test_*.py"
py -3.12 games/coldwar/audit.py --game-dir "游戏目录" --base "工坊中文目录" --font
```
