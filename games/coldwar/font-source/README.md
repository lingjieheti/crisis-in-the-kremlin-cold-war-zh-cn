# Kremlin Donor SC Regular

本目录的字体保存了冷战汉化界面使用的 3,110 个码位及其字形轮廓。字符映射本身就是维护脚本使用的字形清单。字体是项目专用的常规字重子集，内部家族名为 Kremlin Donor SC。SHA-256 为 `5e0db897530eb471208c18ab3af96fe964a6c8887ebded8af95c10850b5d2b6f`。

基础轮廓取自 Noto Sans SC 的常规字重。制作上游捐赠字库时，从 Noto Sans 补充了拉丁扩展字符。本子集保留对应码位的轮廓与字宽，去除了未用字符和排版数据。两份上游许可与署名随附在本目录。[中文字体许可](OFL.txt) · [拉丁字形许可](OFL-Latin.txt) · [固定版本 Noto Sans SC](https://github.com/google/fonts/tree/a85815a42757630ce188fdad368c2dfc444d4773/ofl/notosanssc) · [固定版本 Noto Sans](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notosans)

字体重建使用本机已安装游戏内的 Go Noto Kurrent、多语种字体对象和本目录的子集。产物字体的 SHA-256 为 `451d556e01e42cab95ad3beba0d5c5ca1f6639662272e59e6b177ae94d3f663e`，对应差分为 `92a47e1493caa64e54b96299689cd9329091b47d602f468b525c214a3236efa7`。[重建命令](../README.md)
