# 《克里姆林宫危机：冷战》文本审校记录

本次对照 Steam 构建 26243566（游戏 1.2.5.6）的英文、俄文资源和工坊中文基包。最终模组相对基包改动 1,206 项，含 769 条中文正文和 437 个中文百科链接。正文中的 598 项来自三款合集 v1.0.0，本轮另有 171 项人工对读、判断并修订。[工坊“社区中文翻译”](https://steamcommunity.com/sharedfiles/filedetails/?id=3523398274)

## 查了哪些文本

程序按分区和节点名对齐 134 个分区、18,133 个叶节点。同一父节点下遇到重名叶节点时保留原顺序。英、俄、社区中文、最终中文的键集合一致。最终文本的 XML 属性与英文相同；俄文资源本身在 168 个键上的 XML 属性与英文不同。逐项核验后，没有缺失的正文、已知乱码模式或无法按预期填充的参数。字体覆盖最终文本全部 3,209 个不同可打印字符，其中 3,077 个是汉字。

为排查错段，程序在所属分区内寻找中文段落最接近的英俄原文，并结合重复中文、数字、异常长度、残留外文和段落数量筛选候选。语义检索处理了 17,395 个键，首版输入共 45,687 个不同的正规化字符串。使用本地多语种 MiniLM 模型，取每段开头最多 128 个词元，分别计算中文与英文、俄文的余弦相似度并取均值。它能把复制到另一结局的中文排到前面，也会把英文缩写与中文全称误列为问题。剩余的长叙事没有全部逐句人工通读；下表中的候选数也不能解释为剩余错译数。[模型、配置与版本](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2/tree/e8f8c211226b894fcb81acc59f3b34ba3efd5f42)

| 可复跑的候选规则 | v1.0.0 | 本版 |
| --- | ---: | ---: |
| 有英文来源但中文链接为空 | 467 | 190 |
| 去除格式标记后，英俄数字字面量一致、中文不同 | 419 | 411 |
| 竖线分段数与英文不同 | 51 | 49 |
| 同分区的长中文完全相同，英文有不同写法 | 13 组 | 5 组 |

剩余的 5 组重复已对照。其中包括相同数值效果采用不同英文介词、同一开场叙述的标点差异、相同叙述中的大小写差异等。三处连续外文是军队原名、示威口号和魁北克口号。数字规则会标出日期顺序、十进位与“万”的换算，以及“第六”和“6”的写法。游戏源文与社区中文也各有独立的段落排布。

### 决议的特殊格式

游戏的 `Decision13.BuildEffects` 依次读取 `decision12var0` 至 `decision12var11`，对每行传入同一组 8 个格式参数。英文前两行实际重复了背景介绍。俄文在对应位置给出西欧及指定国家的关系效果。核对游戏的预览和结算函数后，恢复了这些提示，使用实际传入的外交和社会系数。游戏在已经研究万维网时减小这两类系数。激进反对派实力按减法结算，服务业按效能结算。经济联盟各国的关系虽在原版预览中单列，结算中没有对应的单独加成，新译文明确说明了这一点。

上述连续 12 项以游戏调用验收格式参数。其余 18,121 项按官方英文的完整格式串核对。英语和俄语资源本身在 103 个键上使用了不同的数字参数或格式，直接要求三语一律相同会丢失运行时信息。

## 百科链接

使用 MediaWiki 的页面语言链接和 Wikidata 条目身份，查询了 674 个有合适外文维基地址的键。若现有中文、英文、俄文资源所指向的已解析条目身份冲突，则跳过。查得 437 个可确认的中文页，277 个填补原空项，160 个替换原外文链接。47 个多语身份冲突的键均维持旧值。最终仍有 190 个有官方外文链接但中文留空的字段。线上数据库可能改名或更新；检查器会列出有变动的键。[MediaWiki 跨语言链接接口](https://www.mediawiki.org/wiki/API:Langlinks)

## 本地复查

在本目录运行，替换成自己的游戏和工坊目录。第一条只读取文件，在内存中生成并核验最终译本；游戏尚未安装补丁时也能重建目标字体检查字形。第二条会将百科文章标题发往维基官方接口，检查当前的中文链接。

```powershell
py -3 audit.py --game-dir "游戏目录" --base "工坊模组目录" --font --show 5
py -3 audit_wiki.py --game-dir "游戏目录" --base "工坊模组目录"
```

要对照早先生成的本地译本，可在第一条命令中加入 `--compare-xml "旧版text.xml路径"`。旧版对于新定义的决议格式规则会报告差异。使用已在本地准备好的模型，可加入 `--semantic-model "模型目录"` 重跑语义排名；可选步骤需要 NumPy、PyTorch 和 Transformers，安装器和常规核验仅依赖 Python 标准库。

隔离测试使用两版安装器、实际工坊资源和游戏原始字体，注册表读写替换为测试配置。覆盖了新装、重复安装、v1.0.0 已启用或已停用状态直升、第三方模组开关保留、写入前中断、写入后中断并续装、写入后中断直接还原，以及本地文本、图标或记录被改动时停止升级。还原后，字体与原文件逐字节相同。最终生成的本地 `text.xml` 的 SHA-256 为 `1936bf8b50353cbf81bd7b64616bc372e259465bbbc9fcc73e02d2719ede31aa`。

沿用版本的菜单、公告项目数和字体此前已在游戏窗口检查。本轮所修的分支结局、科技和决议已在资源或结算代码中核验；没有在实际存档中逐项触发。
