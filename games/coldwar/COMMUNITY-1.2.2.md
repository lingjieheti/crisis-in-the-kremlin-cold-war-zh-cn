# 1.2.2 汉化更新与复核记录

本版将原工坊中文及此前校订移植至游戏 1.2.5.7 和 1.2.5.8。开发者的桌面更新加入匈牙利事件链、手柄操作和天象馆。后续 1.2.5.8 在游戏内更新说明中增加民族布尔什维克党事件及新的桌面物件。两个构建的文本均取自实际 Steam Windows 游戏。首次安装所用的“社区中文翻译”工坊物品为 3523398274。[开发者公告](https://steamcommunity.com/app/1922740/allnews/) · [社区中文翻译](https://steamcommunity.com/sharedfiles/filedetails/?id=3523398274)

## 玩家可以看到的变化

- 天象馆包含天体、航天任务和展品说明。鸣谢页保留社区翻译团队及字体署名，并从玩家本机游戏读取新增的三条图片作者、许可和原图链接。
- 游戏 1.2.5.8 的 11 场新事件共有 105 个文本项，从民族布尔什维克党成立、索要职位，写到党内分裂、利莫诺夫获释和异见者游行。经济界面解释了下个月预测纳入的战争、路线过渡、延迟生效的决议等因素。联邦德国政治条件保留三处可替换的执政党名称。
- 快速选择窗口提示包含双肩键、摇杆和取消键。游戏依当前手柄决定相应图标。教程的空格、退格、Ctrl、Shift、加减号等键位逐项对照英文，图像设置的分辨率与刷新率使用单行排版。
- 1.2.5.7 更新说明在该构建有 115 项（32、23、32、28）。1.2.5.8 回补了前一版的一项，显示为 116 项；最新公告有 8 项（2、1、3、2）。两版分别采用随该构建提供的分类和项目数。

1.2.5.8 相对 1.2.5.7 增加 163 条、移除 2 条、修改 6 个已有字段。安装程序读取对应版本的英语原件，以父子关系、同名节点的顺序及属性生成中文。正式包中只包含中文差分及重建所需的文件。

1.2.5.8 新增的 11 场事件共 105 个文本项、131 段，已逐条对照英俄原文校译。1.2.5.7 的 617 个剧情、结局与决议文本项对照原文，结合翻译记忆、机器辅助初译和逐段语义筛查。其中 143 条匈牙利相关文本另行专校，并抽查了角色称呼、印度选举中的政党、金额单位、事件分支和游戏参数。

程序比对全部英俄中文键、中文树结构、叶属性、空正文、常见乱码、手柄图标和运行时替换参数。12 条经济决议依照游戏实际传入的参数校验。一个外交事件的英文遗漏了称呼位置，中文按俄文以及游戏在首个参数中传入的人名称呼保留 `{0}`。两个事件结果中原社区译文遗留的右花括号也已修复。

1.2.5.7 的中文差分有 1,671 条，1.2.5.8 另有 169 条。相对原社区文本，1.2.5.8 有 3,065 项中文发生变化，1.2.5.7 有 2,901 项，两者均含 439 个中文百科链接。新版的 3,229 个可打印字符中有 3,093 个汉字；1.2.5.7 有 3,218 个可打印字符、3,082 个汉字。两版均已逐字符核对，缺字为零。另有 188 个百科字段沿用社区原有的空链接。

## 安装与画面复测

在各构建的正版资源副本上，以正式 EXE 内的 Python 和游戏后端分别执行三种新装、从公开 v1.2.1 直升最新、从旧游戏逐次升级到两代新游戏，共五条路径。三代生成的中文、重复安装的时间戳、原始字体、适用版本的原始设置场景、第三方模组和还原后的启用状态均已检查。隔离测试将玩家偏好重定向至临时文件。正式 EXE 的查库及构建检测通过独立验证。

游戏 1.2.5.8 的图像设置已在 100%、105% 和 115% 界面比例下进入实机检查，分辨率和刷新率均完整显示在一行。复测的文字与两侧箭头之间分别有 17 和 16 像素留白。[1920 × 1080 实机对照图](../../docs/interface-review.webp)

最终 EXE 在 Windows 上自动定位到已安装的 Steam 构建 26955082，执行安装与核验均成功。实盘中文 XML 的 SHA-256 是 `4ee66202a495c8fd187f5c410267fe1f2fe7f3c701ac2127d48cb0358bdc4596`。设置场景与字体资源也分别核对了补后指纹。前后对照玩家存档目录，内容一致。

安装后可在源码目录运行下列只读命令，对照自己的游戏、社区基包及重建后的字库。自动化审查覆盖所有文本键。剧情分支的画面和个人存档只能按实际进入过的界面报告。

```powershell
py -3 -B -X utf8 games/coldwar/audit.py --game-dir "Steam 游戏目录" --base "工坊中文目录" --font
py -3 -B -X utf8 -m unittest discover -s games/coldwar -p "test_*.py"
```
